# Lab_Problem_02
Implementation of Merge Sort and Quick Sort in C with comparison counting, followed by merging new sorted records into the existing sorted array.


## Algorithms Used

    1. Merge Sort– Sorts the given records in ascending order using the divide-and-conquer approach.
    2. Quick Sort – Sorts the records in ascending order using the last element as the pivot.
    3. Merge Procedure– Combines two sorted arrays into one sorted array without sorting all elements again.

    Comparison Counting:
    - Counts element comparisons during the merging process of Merge Sort.
    - Counts element comparisons during the partitioning process of Quick Sort.
